Quer apenas uma distribuição gratuita e confiável?
Use Temurin.

 Está rodando em OpenShift?
Use Red Hat OpenJDK.

Quer suporte corporativo e independência de plataforma?
Use Azul Zulu.

Quer apenas desenvolver localmente?
